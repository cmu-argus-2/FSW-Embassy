## Installing required packages
```
brew install picotool
cargo install defmt-print
```
## Binaries
Binaries are found in the `fsw-bin` directory. Navigate to the directory for more instructions on how to run them.

## Tests
Software in the loop tests are found in the `fsw-test` directory. Navigate to the directory for more instructions on how to run tests.

## Library
The library is stored in the `fsw-lib` directory.
